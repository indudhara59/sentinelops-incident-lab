# Changelog

This project follows a phased portfolio roadmap. It has not published a stable semantic-version release.

## Unreleased — Phase 10

- Added Vercel and Render/Railway deployment configuration, single-worker API container, readiness, compression, and troubleshooting guidance.
- Hardened WebSocket origin/capability checks, validation-error redaction, production CORS, and response headers.
- Added CI, dependency audits, OpenAPI validation, security/threat/accessibility/performance reviews, community files, and portfolio presentation.

## Phases 1–9

- Built the public foundation, scenario catalog, deterministic operations workspace, observability tools, authoritative FastAPI transport, scoring/reports, Atlas/Auth.js dashboard, private scenario builder, five built-in scenarios, and learning center.

See [the roadmap](docs/roadmap.md) for the phase-by-phase feature history.
