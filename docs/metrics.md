# Metric dashboards

Metrics are deterministic simulated samples for request rate, error rate, p50/p95/p99 latency, CPU, memory, active database connections, database connection-pool utilization, queue depth, and service restarts.

Players can choose a service and time window. Charts share a synchronized keyboard-focus cursor and display incident thresholds, alert annotations, and fictional deployment markers. A focused point or the visible range can be collected as evidence.

Every chart has a table alternative with the same rounded values and timestamps. Reduced-motion preferences disable transitions, and the fixed history window prevents chart work from growing with session length.
